## Overview

### The Challenge

Users should be able to:

- View an optimal layout across different screen sizes.
- See hover states for interactive elements.
- Search for GitHub users by username.
- View relevant information about the searched GitHub profile.
- Switch between light and dark themes.

### What I Learned

During this project, I practiced building a React application that retrieves and displays data from an external API.

Some of the main concepts I worked with were:

- Breaking the interface into reusable React components.
- Managing component state with React Hooks.
- Fetching data from the GitHub API.
- Handling form submissions and user input.
- Organizing API requests into a separate service.
- Implementing responsive layouts based on a Figma design.
- Working with light and dark themes.
- Debugging errors and improving the application incrementally.

This project also helped me understand the importance of separating responsibilities between components and keeping the code organized.

### AI Collaboration

I used AI tools, including ChatGPT and Codex, as development assistants throughout the project.

They helped me organize implementation steps, investigate errors, review code, and identify potential improvements.

Rather than relying exclusively on generated code, I worked through the application incrementally, reviewing the implementation and learning about the concepts involved before moving on to the next step.

This approach helped me explore how AI can support the development workflow while reinforcing my understanding of React and TypeScript.

### Continued Development

I want to continue improving my skills in:

- React state management and component architecture.
- TypeScript and type-safe API integration.
- Error handling and loading states.
- Responsive design and accessibility.
- Writing maintainable code and testing application behavior.
- Making better technical decisions when working with AI-assisted development tools.
